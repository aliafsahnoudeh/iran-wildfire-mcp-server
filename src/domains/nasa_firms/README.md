# NASA FIRMS Area API

## How to get the API key:

1. Sign up for the FREE API here:
   (https://firms.modaps.eosdis.nasa.gov/api/map_key)[https://firms.modaps.eosdis.nasa.gov/api/map_key]
2. Click "Get MAP_KEY" and follow the instructions.
