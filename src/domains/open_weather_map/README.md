(https://openweathermap.org/api/geocoding-api)[https://openweathermap.org/api/geocoding-api]

Example of API call:

```
http://api.openweathermap.org/geo/1.0/reverse?lat=51.5098&lon=-0.1180&limit=5&appid={API key}
```
